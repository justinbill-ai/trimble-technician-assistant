Groundworks CSV formatter

Map columns and export pile CSV for Groundworks import

Upload a drill/pile CSV from TBC, Siteworks, or a data collector. Map your columns to the Groundworks import layout, preview the result, then download or email a semicolon-separated file for Project Setup (Groundworks v2.0+).

Groundworks export columns (semicolon-separated): ID;X;Y;Z;Orientation;Inclination;Rotation;Length. Orientation, Inclination, and Rotation are in degrees.

1. Upload & options

Match the coordinate and length units in your uploaded file before mapping and preview. Groundworks import expects the same units as your project.

No unit conversion. This formatter does not convert between metric and US feet — it treats values as already in the units you select above, which matches how pile coordinates are usually exported from TBC or Siteworks.

2. Map columns

Drag a column from your imported file onto each Groundworks field, or enter a fixed value when your CSV does not include that column. Required: ID, X, Y, Z, and Length (map or fixed value).

Orientation / Inclination / Rotation are in degrees. For vertical piles, start with 0 for each and confirm in a test Groundworks import. Inclination is typically measured from vertical — verify in your project whether tilt follows the Orientation heading.
