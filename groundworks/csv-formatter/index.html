Groundworks CSV Formatter BETA

Map columns and export pile CSV for Groundworks import

BETA tool in development. Upload a drill/pile CSV from TBC, Siteworks, or a data collector. Map your columns to the Groundworks import layout, preview the result, then download or email a semicolon-separated file for Project Setup (Groundworks v2.0+).

Groundworks export columns (semicolon-separated): ID;X;Y;Z;Orientation;Inclination;Rotation;Length. Orientation, Inclination, and Rotation are in degrees.

1-based row numbers from your CSV file. Separate with commas; use ranges like 3...6 or 3-6 (same style as TBC). Example: 1,2...4,7 skips rows 1, 2, 3, 4, and 7. Row 1 is always skipped when the header box above is checked.

2. Map columns

Drag a column from your imported file onto each Groundworks field, or enter a fixed value when your CSV does not include that column. Required: ID, X, Y, Z, and Length (map or fixed value).

Orientation / Inclination / Rotation are in degrees. For vertical piles, start with 0 for each and confirm in a test Groundworks import.
